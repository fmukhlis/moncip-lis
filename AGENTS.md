### Git and Version Control Rules

- Never stage files or changes. Do not run `git add` or any other command that modifies the Git staging area.
- Never create commits or amend existing commits unless explicitly instructed.
- Do not stash, reset, revert, or discard any changes unless explicitly instructed.
- You may inspect Git status and diffs using read-only commands such as `git status` and `git diff`.
- Leave all modified and newly created files unstaged. I will review the changes and handle staging and commits myself.
